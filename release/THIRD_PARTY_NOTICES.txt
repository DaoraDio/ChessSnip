Third-party software and model notices
======================================

Offline text and QR reading
--------------------------
Text recognition uses Windows.Media.Ocr, the on-device OCR API included with
Windows. It makes one OCR pass and uses the language resources installed for
the current Windows user; ChessSnip does not bundle OCR models or upload snips.

The Python projection for the Windows Runtime APIs is PyWinRT, distributed
under the MIT License in PyWinRT_LICENSE.txt.

The QR reader uses zxing-cpp, distributed under Apache License 2.0. Its
license is included in ZXing_CPP_LICENSE.txt.

chessimg2pos
------------
The bundled chess-piece classifier is based on the pretrained model and model
architecture from chessimg2pos by Marcodicio. The original PyTorch model was
converted to ONNX for ChessSnip's compact, CPU-only local inference runtime.
The piece classifier architecture and weights are licensed under the MIT
License. Project: https://github.com/mdicio/chessimg2pos

Chessboard finder
-----------------
ChessSnip's screen-board detector is adapted from the chessboard_finder.py
algorithm in chessimg2pos by Marcodicio. It uses NumPy and Pillow and was
adjusted to return screen-image board bounds and handle current NumPy versions.
