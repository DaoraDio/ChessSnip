ChessSnip for Windows
====================

Run ChessSnip.exe. This is a standalone, single-file build; Python and other
ChessSnip runtime files do not need to be installed or copied alongside it.

Requirements: 64-bit Windows 10 or Windows 11.

Quick start
-----------
- Click New snip or press Ctrl+Shift+X to capture the screen.
- To open directly in capture mode, start `ChessSnip.exe --snip`.
- Press Esc to cancel a capture.
- Captures are copied to the clipboard automatically. Use Save as… to keep a
  permanent image file.
- Click Chess → PGN to recognize a chess position locally and review/export it.

Paint must be installed to use Open in Paint. Open in Lichess requires a web
browser and an internet connection. The chess model and recognition engine are
already included in ChessSnip.exe.

Keep THIRD_PARTY_NOTICES.txt with the executable when redistributing it.
